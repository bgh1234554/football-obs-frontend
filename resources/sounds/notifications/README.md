# 알림음 음원

8비트 알림은 홀수 배음을 더한 사각파 계열 음색으로 직접 합성했습니다. 외부 음원은 사용하지 않습니다.

| 파일 | 구성 | 용도 |
| --- | --- | --- |
| `eightbit-board.wav` | C6·G6, 약 0.19초 | 점수·득점자 깜빡임의 짧은 두 음 |
| `eightbit-event.wav` | G5·C6·G6, 약 0.27초 | 신규 이벤트의 짧은 세 음 |

44.1kHz 모노 PCM WAV입니다. 음높이는 미끄러지지 않고 짧게 끊어 바뀌며, 빠른 발음과 계단형 감쇠로 펄스 채널의 질감을 냅니다. 깜빡임 파일 끝에는 재생 구간을 위한 무음을 덧붙였습니다. 두 알림은 같은 음색을 사용하며 승리·스테이지 클리어 연출은 사용하지 않습니다. 나머지 세트는 Web Audio로 합성합니다.
