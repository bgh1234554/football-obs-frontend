# 전체 포메이션 전환 검토

검토 기준일: 2026-10-01. 지원하는 23개 포메이션의 서로 다른 253개 조합을 검토했다. 아래 한 행은 양방향 전환을 나타내며, 역방향은 같은 선수 대응의 정확한 역순이다. 동일 포메이션 23개와 양방향을 포함하면 총 529개 경우다.

## 결과

- 직접 대응 51개, 두 단계 합성 89개, 세 단계 합성 78개, 네 단계 합성 35개.
- 이번 검토 전 배치와 비교해 97개 조합의 선수 대응을 보완했다.
- 모든 조합에서 공통 수비 역할 유지, 공격수 수가 같을 때 기존 공격수 유지, 반대쪽 측면으로 넘어가는 이동 없음, 선수·빈자리 보존 및 정확한 왕복 복원을 검증했다.
- 자료로 확인한 전술 구조를 우선 사용한다. 개별 선수의 좌우 선택 및 여러 단계를 합성한 결과는 앱의 기본 배치 정책이며, 모든 팀의 실제 전환을 뜻하지 않는다.

[근거 자료와 기본 전환 규칙](formation-transitions.md)을 함께 참고한다. 경로는 선수 대응을 계산하는 내부 연결이며 UI에서 중간 포메이션을 표시하지 않는다. 역할 표기가 같아도 좌표의 높이와 폭은 바뀔 수 있다.
